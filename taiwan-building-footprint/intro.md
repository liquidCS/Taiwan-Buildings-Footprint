# Root Intro 

This project contains three main parts:
1. OSM Address and Building Analysis
2. Binary Map Tiles Generation
3. Building Segmentaiton


### Why 
I have been using OpenStreetMap (OSM) for nearly five years now, and I used to edit a lot of buildings, but it takes lots of time. Taiwan has fewer buildings footprints than the surrounding countries such as, Japna and Filipions, because most of them have data from [Microsoft Building Footprints](https://github.com/microsoft/GlobalMLBuildingFootprints). According to Microsoft's assessment, this is likely due to low accuracy, outdated satellite images, or poor image quality.

Since then, I have wanted to build a tool that can enhance the efficiency of editing new buildings to contribute back to the OSM community. This Jupyter book contains everything I have created throughout the process.
